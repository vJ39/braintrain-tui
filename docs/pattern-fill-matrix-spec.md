## 概要

「パターン補完」(`src/game/pattern_fill.rs`)を、現状の「1つの図形が一定角度ずつ回転する等差数列を9マスに敷き詰める」出題から、行・列でそれぞれ別の規則を持つ2軸型(レーヴン漸進的行列に近い形式)に作り直す。

## 現状の問題

- `generate_beginner`/`generate_intermediate`/`generate_advanced`のいずれも、9マス全体に対して1種類の規則(全マス同じ/行ごとに同じ/角度が一定間隔で増える)を敷いているだけで、実質的に1次元の数列予測(既存の「数列予測」ゲームと同じ思考)になっている

## 新しい出題方式: 行・列で別規則の2軸型

3x3グリッドの各マスの図形(`Cell { shape_index, angle_deg }`)を、以下のように行の規則と列の規則の組み合わせで決める。

- **行の規則**: 行(0〜2)ごとに図形の種類(`shape_index`)を変える(同じ行の3マスは同じ図形)
- **列の規則**: 列(0〜2)ごとに回転角度(`angle_deg`)を変える(同じ列の3マスは同じ角度)

つまりマス`(row, col)`の図形は「行`row`に対応する図形種類」を「列`col`に対応する回転角度」で回転させたものになる。空欄マスの正解は、行の規則(図形種類)と列の規則(回転角度)の両方を満たす組み合わせでなければならない。

## 難易度

- Beginner: 行の規則(図形種類)のみを使う。列は全て同じ角度(0度)にして、実質1軸の見分けやすい出題にする(現状のIntermediateに近い形)
- Intermediate: 行の規則(図形種類)+列の規則(回転角度)の両方を使う。誤答の選択肢には「図形種類は合っているが角度が違う」「角度は合っているが図形種類が違う」を混ぜ、両方の軸を見る必要があるようにする
- Advanced: 回転角度の刻みを増やす・図形の見分けがつきにくい角度差にする等で紛らわしさを上げる。誤答には、行の規則だけを満たす・列の規則だけを満たす、という「片方だけ正しい」選択肢を必ず含める

## 対象ファイル

- `src/game/pattern_fill.rs`(`generate_beginner`/`generate_intermediate`/`generate_advanced`・`Question`生成・選択肢生成ロジックの書き直し)

## テスト観点

- 各難易度で、生成されたグリッドが行の規則・列の規則(該当する難易度で使うもの)を満たしていること
- 空欄マスの正解が、行と列両方の規則から一意に定まること
- 選択肢に正解が必ず1つ含まれること
- Intermediate/Advancedで、「片方の軸だけ正しい」紛らわしい誤答が混ざること
- 既存のクリック判定・キー操作・スコア記録の仕組みが壊れていないこと
- 描画がパニックしないこと
