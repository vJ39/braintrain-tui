## 概要

暗算スピードの問題文(式)と選択肢(こたえ)の文字を、画像プロトコル対応端末では大きく表示する。

## 方式

`fontdue`クレート(v0.9)を新規依存として追加し、Rust側で動的にTrueTypeフォントをラスタライズして文字列→画像(RgbaImage)に変換する。フォントは既存の出題文字と同じ`/System/Library/Fonts/ヒラギノ角ゴシック W6.ttc`を使う(`fontdue::Font::from_bytes`はTTCを直接ロードできることを検証済み)。

- 表示する文字列(例: 問題式「12 + 8 = ?」、選択肢「42」)の各文字を`font.rasterize(ch, px)`でラスタライズし、共通のベースライン(`font.horizontal_line_metrics(px)`のascent、各グリフの`ymin`)に揃えて1枚のRgbaImageへ順に配置していく(advance_widthで次の文字の位置を進める)
- 合成したRgbaImageを、イロピッタンと同じ仕組み(黒文字→背景色に合成→画像プロトコルで表示)でそのまま流用する
- 選択肢(4つ)もそれぞれ同じ方式で拡大表示する
- キャッシュ: 文字列(問題式・各選択肢)が変わらない間は再ラスタライズ・再エンコードしない(既存の`LabelRenderer`のキャッシュ機構と同じ考え方)

画像プロトコル非対応端末では、現状通りの通常サイズのテキスト表示のままにする(フォールバック)。

## スコープ外

- 出題ロジック(`generate_question`)・難易度別パラメータは変更しない
- レイアウト(問題文エリア/選択肢エリア/フッターの分割)の大枠は変更しない。文字を大きくした分、各エリアの高さ配分は調整してよい
