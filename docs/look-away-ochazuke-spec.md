## 概要

「ヤッホー」(look_away)を、お茶漬け屋の親父(白い割烹着)とカウンター越しに対峙する形に全面改修する。プレイヤーは客としてカウンターの前に座り、親父が真正面にいる構図。親父の前にはお茶漬けセットが置かれている(舞台設定・演出のみで、プレイヤー操作の対象ではない)。

既存のフェイントシステムは廃止し、「ヤー」(指さして叫ぶ)と「やっほー」(呼びかけ)の2イベントのみにする。判定時間を400msに短縮し、反応が遅れるほど段階的に減るハート制にする。10問セッション制(ROUNDS_PER_SESSION=10)は維持し、ハートはそのセッション内でのライフとして機能する。

## ゲームフロー

1. 待機(既存のIdle、時間はランダム)
2. 待機が終わったら、次のどちらかのイベントが始まる(フェイントなし)
   - 「ヤー」: 左右どちらかを指して叫ぶ。プレイヤーは指された方向と逆の矢印キーを押す
   - 「やっほー」: プレイヤーはSpaceキーを押す
3. 判定
   - RESPONSE_SAFE_WINDOW(400ms)以内に正しい入力: 正解、ハート減少なし
   - 400ms超過後に正しい入力、または誤った入力、または無反応でMAX_RESPONSE_WINDOW(800ms)経過: 不正解。減るハートの個数は反応の遅れに応じて増える(下記penalty計算)
4. 正誤を表示し、次の問題へ(10問で終了、または途中でハートが0になったらGAME OVER)

## 判定・ペナルティ計算

- `RESPONSE_SAFE_WINDOW = 400ms`: これ以内に正しい入力ができれば正解、ペナルティ0
- `PENALTY_STEP = 80ms`: 400ms超過分をこの単位で区切って数える
- `MAX_RESPONSE_WINDOW = 800ms`: これを過ぎても入力が無ければ自動的にタイムアウト確定(elapsed=800msとして計算)
- 不正解時のペナルティ個数: `penalty = 1 + floor((elapsed_ms - 400) / 80)`(elapsedはその判定が確定した時点での経過時間。誤入力なら入力された瞬間、無反応ならMAX_RESPONSE_WINDOW)
  - 例: 420ms(超過20ms)で誤答 → penalty=1
  - 500ms(超過100ms)で誤答 → penalty=2
  - 800ms(無反応・超過400ms)→ penalty=6(ハート5個を上回るため実質即GAME OVER相当)
- ハートは `saturating_sub` で0未満にならないようにする
- `MAX_LIVES = 5`(初期値、既存の3から変更)

## 画像仕様(4種、Gemini生成でユーザーが用意)

カウンター越しに親父(白い割烹着)がプレイヤーの正面にいる構図。手前にお茶漬けセットが乗っている。

1. `look_away_normal`: 待機中の穏やかな表情
2. `look_away_shout_right`: 右を指して「ヤー」と叫んでいる(怒った/勢いのある表情)
3. `look_away_shout_left`: 左を指して叫んでいる版(right画像の左右反転で対応、べーの軽トラ画像と同じ方式)
4. `look_away_yahho`: 「やっほー」と呼びかけている(明るい表情)

画像プロトコル非対応環境は既存のテキスト絵にフォールバックする(べーの軽トラ視点と同じ設計)。

## BGM

専用のBgmCategory(例: `BgmCategory::LookAway`)を新設し、演歌の音源(ユーザー提供)をそこに割り当てる。音源が届くまではコード上の受け皿だけ用意し、既存の共通Playing用BGMにフォールバックする。

## 変更しないもの

- 10問セッション制(ROUNDS_PER_SESSION=10)
- GAME_ID(`look_away`)・DISPLAY_NAME(「ヤッホー」)
- 1問目のみの「3.2.1.GO!!」カウントダウン演出
- ScoreTrackerでの正誤記録の枠組み

## 廃止するもの

- フェイント(指さすだけで叫ばない演出)関連: `Event::Feint`, `Phase::Feint`, `AfterFeint`, `FEINT_DURATION`, `FEINT_RATE`, `REPOINT_RATE`, `RESUME_WAIT_MS`, `MAX_FEINTS_PER_ROUND`

## 対象ファイル

- `src/game/look_away.rs`(判定ロジック・画像描画)
- `src/audio/mod.rs`(BgmCategory新設)
- `assets/image/look_away/`(新規、4枚の画像)
- `assets/audio/bgm/look_away/`(新規、演歌BGM。届くまで空)

## テスト観点

- 400ms以内の正しい入力は正解になり、ハートが減らないこと
- 400ms超過後の正しい入力・誤入力・無反応(800ms経過)は不正解になり、超過時間に応じてpenalty個数のハートが減ること(80ms刻みで段階的に増えること)
- ハートは0未満にならないこと(saturating)
- フェイントに関する状態・分岐が完全に無くなっていること
- 10問終えたらCLEAR、ハートが0になったらGAME OVERになること(既存動作の維持)
- 画像プロトコル非対応環境ではテキスト絵にフォールバックすること
