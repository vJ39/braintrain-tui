## 概要

背景色(display_color)と、中央に大きく表示される文字(label)の色の意味が一致しているかを判定するゲーム。

## 色パレット

| 色 | 漢字表記 | カタカナ表記 |
|---|---|---|
| 赤 | 赤 | レッド |
| 青 | 青 | ブルー |
| 緑 | 緑 | グリーン |
| 黄 | 黄 | イエロー |
| 紫 | 紫 | パープル |
| 白 | 白 | ホワイト |
| 茶 | 茶 | ブラウン |
| 橙 | 橙 | オレンジ |
| 桃 | 桃 | ピンク |

難易度別の色プール:

| 難易度 | 使用する色 | 表記 |
|---|---|---|
| 初級 | 赤・青(2色) | 漢字のみ |
| 中級 | 赤・青・緑・黄(4色) | 漢字のみ |
| 上級 | 赤・青・緑・黄・紫・白・茶・橙・桃(9色) | 漢字/カタカナを出題ごとにランダム選択 |

## 出題生成

1. 背景色(display_color)を、その難易度の色プールから**前回の出題の背景色を除いて**ランダムに選ぶ(連続で同じ背景色にならない)
2. 一致/不一致(is_match)をランダムに決める
3. 上級では表記(漢字/カタカナ)を出題ごとにランダムに決める。初級/中級は常に漢字
4. is_match=true の場合、label は display_color と同じ色の(選んだ表記の)ラベル
5. is_match=false の場合、label は display_color 以外の色から1色ランダムに選んだ(選んだ表記の)ラベル

## 画像アセット

`assets/image/reaction/` に、黒文字・透明背景のPNGを色ごと・表記ごとに用意する(既存の赤/青/緑/黄の漢字4枚に加えて追加):

- 漢字5枚(新規): 紫(murasaki.png)・白(shiro.png)・茶(cha.png)・橙(daidai.png)・桃(momo.png)
- カタカナ9枚(新規): レッド(reddo.png)・ブルー(buruu.png)・グリーン(guriin.png)・イエロー(ieroo.png)・パープル(paapuru.png)・ホワイト(howaito.png)・ブラウン(buraun.png)・オレンジ(orenji.png)・ピンク(pinku.png)

既存の漢字画像は正方形(512x512)。カタカナは3〜4文字と横に長いため、画像自体を横長(例: 幅1536x高さ512、文字数に応じて幅を調整)で生成し、フォントサイズも収まるよう調整する。

表示側(`glyph_area`/`compose_label_image`)は正方形前提だった処理を、画像本体のアスペクト比に合わせて表示エリアに収まる最大サイズを計算する処理に変更する(縦長・横長どちらの画像も歪まず表示できるようにする)。

## 背景色(RGB)

新規5色を `background_rgb` に追加する。黒文字が読みやすい明るさで、既存4色と重複しない値にする。

## スコープ外

- 一致/不一致の判定ロジック自体は変更しない
- フォールバック表示(画像プロトコル非対応端末のテキスト表示)も、選ばれた表記の文字列をそのまま表示するだけで、レイアウト変更は不要
