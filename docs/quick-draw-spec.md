## 概要

いつ来るかわからない合図を待ち、合図が出た瞬間に反応する反射神経計測ゲーム。GAME_ID: `quick_draw`

## ルール

1. ラウンド開始時は「待機」状態。画面は落ち着いた色(暗いグレー)で「まだ待て」を表示する
2. ランダムな待機時間の後、合図(明るい緑の全画面表示+「今だ!」)に切り替わる
3. 合図が出た後にキー(Enter/Space)を押すかクリックすると、合図が出てから押すまでの経過時間(ms)を反応時間として記録し、次のラウンドへ進む
4. 合図が出る前に押すとフライングとして失敗扱いになり、次のラウンドへ進む(反応時間の代わりに難易度ごとの固定ペナルティ値を記録する)
5. 合図後の反応にはタイムアウトを設けない(押すまで待つ)

## 難易度別パラメータ

難易度による違いは待機時間の範囲のみ(フェイント演出は無し)。

| 難易度 | 待機時間の範囲 |
|---|---|
| 初級 | 1.0〜2.5秒 |
| 中級 | 1.0〜4.0秒 |
| 上級 | 0.8〜5.0秒 |

## スコア/結果

既存の`ScoreTracker`/`GameResult`と同じ枠組み。

- 1セッション = 3ラウンド
- 正解(合図後に反応): `tracker.record(true, latency_ms)` — 合図から押すまでの経過時間
- フライング: `tracker.record(false, fail_latency_ms)` — 難易度ごとの固定ペナルティ値(count_maniaのfail_latency_msと同じ考え方)

## 操作

キー(Enter/Space)とマウスクリック(画面のどこでも)の両方に対応する。
